
Usage: make <target>

Targets:
  help              Print targets and variables
  init              Initialize project (bun install, openapi.yaml, api-types, embed stub)
  start             Init, then start backend (go run) + frontend (vite) in dev mode
  stop              Stop dev processes (backend shuts down gracefully via admin API, frontend is killed)
  restart           Rebuild and restart the backend only (live frontend is kept; full start when frontend is down)
  smoke-test        Run the smoke harness against the running dev stack (no restart; `make start` first)
  upload-plugins    Upload every store .lua plugin via the admin listener (no restart)
  status            Show dev server status
  log               Query persisted events (follows on TTY, dumps and exits otherwise)
  log-frontend      Tail frontend log (follows on TTY, dumps and exits otherwise)
  browser           Open dashboard in browser (http://localhost:38080)
  clean             Stop + clean ignored files (keeps .env files and SQLite databases)
  build             Init, then build frontend + all PLATFORMS binaries
  install           Init, then build host release binary into ~/.local/bin (refuses when running)
  publish           Cut and push the next release tag (TYPE or VERSION; CI builds)
  go-vet            Run go vet (PKG scopes packages, default "./...")
  go-test           Run go test (PKG scopes packages, default "./...")
  go-test-race      Run go test -race (PKG scopes packages, default "./...")
  sql-policy-test   Enforce typed GORM conditions (no raw SQL outside allowlist)
  go-fmt            Apply gofmt to both Go modules (PATHS scopes files/dirs)
  go-fmt-check      Fail when gofmt would reformat anything (PATHS scopes)
  go-tidy           Tidy both Go modules
  check-frontend    Run svelte-check (frontend type check)

Variables:
  VERSION            Release version for build. Default: latest git tag, else "dev"
  HOST               Bind host. Default: "localhost"
  PORT               Single listener port (dashboard + /v1 + /api). Default: "38080"
  ADMIN_PORT         Admin listener port (loopback-only, no auth; empty disables). Default: "38082"
  SCOPE              Start/stop set: "all" or "backend" (frontend kept, hot reload applies it). Default: "all"
  URL                Dashboard URL for browser. Default: "http://$(HOST):$(PORT)"
  LOG_LEVEL          Server log level. Default: "info"
  DB_PATH            Database file for the server. Default: "~/.local/share/llm-router/llm-router.dev.sqlite3"
  CACHE_PATH         Cache database file for the server. Default: "~/.cache/llm-router/llm-router.cache.dev.sqlite3"
  EVENTS_PATH        Events database file for the server. Default: "~/.local/state/llm-router/llm-router.events.dev.sqlite3"
  EVENTS_RETENTION_DAYS  Event retention in days. Default: "3"
  LUA_POOL_BUCKET_SIZE  Idle Lua states stored per plugin bucket. Default: "16"
  DEV_UI_REDIRECT    Dashboard redirect origin for dev. Default: empty
  ENV_FILE           Dotenv path for the server. Default: "~/.config/llm-router/.env.dev"
  PID_FILE           Pidfile for dev processes. Default: "~/.local/state/llm-router/llm-router.dev.pid"
  SMOKE_PLUGINS      Comma plugin names for smoke-test (or "all"). Default: "all" (every store plugin)
  SMOKE_TARGETS      Comma targets for smoke-test. Default: "completions,messages"
  UPLOAD_STORE_DIR   Store dir for upload-plugins. Default: "../../llm-router-store/llm-router-plugins"
  HARNESS            Harness to validate (CI only): claude, codex or opencode (required)
  HARNESS_RUN_ROOT   Run directory root for harness-test artifacts. Default: "~/.cache/llm-router/harness"
  HARNESS_PHASE_TIMEOUT  Timeout per harness-test invocation. Default: "5m"
  PLATFORMS          Platforms for build. Default: "windows/amd64 ..."
  TYPE               Release bump for publish: fix|minor|major (or VERSION=X.Y[.Z] to force)
  PKG                Package scope for go-vet, go-test and go-test-race. Default: "./..."
  PATHS              Space-separated files/dirs for go-fmt and go-fmt-check. Default: whole tree
  LINES              Initial tail size for log-frontend. Default: "100"
  FOLLOW             Force log follow (1) or dump-and-exit (0). Default: follow on TTY only
  EVENTS_SEVERITY    Minimum event severity for log (0-4). Default: empty (all)
  EVENTS_ID          Single event id for log. Default: empty
  EVENTS_START       RFC3339 start for log. Default: empty
  EVENTS_END         RFC3339 end for log. Default: empty
  EVENTS_LIMIT       Max events for log. Default: "50" (LINES fallback)
  EVENT_FILTERS      Space-separated event filters for log ("k=v bare-key !k !k=v"). Default: empty
  NO_SKIP            Disable skipping of bun install + OpenAPI generation. Default: "0" (truthy: 1/true/yes/on)

Examples:
  make init
  make go-test PKG=./internal/services/router/
  make go-vet PKG=./internal/services/router/...
  make go-fmt-check PATHS="internal/server scripts/smoke"
  make start
  make start HOST=0.0.0.0 PORT=3000
  make restart
  make build
  make build PLATFORMS="linux/amd64 darwin/arm64"
  make publish TYPE=fix
  make publish VERSION=1.3.1
